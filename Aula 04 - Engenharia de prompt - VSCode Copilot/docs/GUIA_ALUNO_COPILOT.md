# 📖 Guia do Aluno — Aula 04: Observabilidade com VS Code e GitHub Copilot

Bem-vindo à Aula 04! Hoje você aprenderá a usar o **GitHub Copilot no Visual Studio Code** para acelerar seu trabalho diário com observabilidade, Grafana, Prometheus e Loki.

---

## 🛠️ 1. Preparando o seu VS Code
1. Abra esta pasta no VS Code: `File -> Open Folder...\` e selecione `Aula 04 - Engenharia de prompt - VSCode Copilot`.
2. Verifique se a extensão **GitHub Copilot** e **GitHub Copilot Chat** estão ativas (ícone no painel lateral ou barra inferior).
3. O arquivo `.github/copilot-instructions.md` já fornece todo o contexto técnico do nosso laboratório para o Copilot.

---

## ⌨️ 2. Atalhos Essenciais do Copilot no VS Code
- `Ctrl+Alt+I` (ou `Cmd+Option+I` no Mac): Abre o painel lateral do **Copilot Chat**.
- `Ctrl+I`: Abre o Copilot Inline direto na linha de código onde você estiver editando.
- `Ctrl+Shift+P` -> Digite `Tasks: Run Task`: Permite rodar tarefas automáticas do laboratório (Deploy, Subir Stack, Gerar Tráfego e Limpeza).

---

## 🚀 3. Principais Comandos de Chat
- `@workspace`: Faz o Copilot indexar todos os arquivos da pasta e responder com base na arquitetura real.
- `#file:stack/compose.yaml`: Aponta o foco da pergunta diretamente para um arquivo específico.
- `/explain`: Pede explicação detalhada de uma query ou trecho de código.
- `/fix`: Pede para corrigir erros de sintaxe ou de configuração.
