Os arquivos `Grafana_Visualizando_Dados_V1*`, `Grafana_Visualizando_Dados_V2.pptx`, `caderno-exercicios.*` e os geradores desta pasta pertencem às versões anteriores. Seus horários, divisão por dias e instruções podem divergir do curso atual. Não distribua esses PDFs como material vigente.

Nenhum gerador antigo foi executado nesta organização. Os materiais atuais, os exercícios manuais e os [exemplos opcionais para importar](../Curso_Grafana_Green_V8/exemplos-importaveis/README.html) são consultados pelo índice principal.
