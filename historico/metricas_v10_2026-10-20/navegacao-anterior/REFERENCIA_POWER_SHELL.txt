INICIAR O LABORATÓRIO DO ALUNO
Primeiro abra o Docker Desktop, ou confirme o Docker Engine ativo com Compose.
.\iniciar-lab-alunos.ps1

O lançador delega a Curso_Grafana_Green_V9\iniciar-lab.ps1, que inicia somente a stack local
do aluno. Ele não chama os scripts Azure do professor.

CONFERIR A STACK LOCAL
Set-Location -LiteralPath '.\Curso_Grafana_Green_V9\lab\tutorial-environment'
docker compose -p green-fundamentals ps
docker compose -p green-fundamentals logs --tail 50

ENDEREÇOS NO NAVEGADOR
Grafana: http://localhost:3300
Aplicação: http://localhost:38081
Receptor Webhook: http://localhost:38090

PARAR A STACK LOCAL PRESERVANDO OS VOLUMES
Na pasta Curso_Grafana_Green_V9\lab\tutorial-environment:
docker compose -p green-fundamentals stop

Não é necessário apagar volumes para encerrar a aula. Os procedimentos de limpeza
e recriação, quando necessários, devem ser executados conscientemente e fora deste guia.
