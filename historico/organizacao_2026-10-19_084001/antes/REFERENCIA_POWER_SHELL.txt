     "secondary": "F46800",     ← cor secundária (hover, detalhes)
     "accent": "10B981",        ← cor de destaque (sucesso, OK)
     "background": "FFFFFF",    ← fundo
     "text": "1F2937"           ← texto principal
   }

   Use a paleta da sua escola. Cores em HEX sem o "#".

11. TROUBLESHOOTING
================================================================================

PROBLEMA: Docker não inicia no WSL
   - Abra o Docker Desktop, vá em Settings > Resources > WSL Integration
   - Ative a integração com sua distro (Ubuntu)
   - Reinicie o WSL: wsl --shutdown

PROBLEMA: Porta 3000 já em uso
   - Descubra o que está usando: netstat -ano | findstr :3000
   - Mate o processo: taskkill /PID <numero> /F
   - Ou mude a porta no docker-compose.yml: "3001:3000"

PROBLEMA: Playwright não instala o Chromium
   - Rode: python -m playwright install --with-deps chromium
   - Se falhar, tente: pip install --upgrade playwright

PROBLEMA: Imagens não aparecem no PPTX regenerado
   - Verifique se a pasta assets/screenshots tem os .png
   - Rode o capture novamente: python scripts\capture_grafana_screenshots.py
   - Depois rode o gerador: cd docs && node generate_pptx_with_screenshots.js

PROBLEMA: Logo não aparece no Grafana
   - Verifique se o arquivo existe: E:\01_Projetos\Curso Grafana\assets\logo\logo.png
   - Formato deve ser PNG (não JPG, não SVG)
   - Rode novamente: python scripts\apply_brand.py
